# Customer Churn Prediction

## Project Overview
This project aims to predict customer churn using Machine Learning classification algorithms.

## Dataset
IBM Telco Customer Churn Dataset.

- Number of records: 7,043
- Number of features: 20 predictors and 1 target
- Target variable: `Churn`

## Objectives
- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Handling Class Imbalance
- Machine Learning Model Comparison
- Model Evaluation
- Model Explainability using SHAP

## Models
Models will be evaluated and compared throughout the project.

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC / Average Precision

## Tools
Python, Pandas, NumPy, Scikit-learn, Imbalanced-learn, XGBoost, SHAP, Matplotlib, Seaborn, Jupyter Notebook, Git and GitHub.
